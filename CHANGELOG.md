# Changelog

## 2026-06-07

### Что изменилось

- Google Play теперь идёт через VPN, как в оригинальном DEFAULT-профиле RoscomVPN.
- Все ссылки для Shadowrocket переведены на jsDelivr CDN, чтобы конфиг и списки правил стабильнее скачивались.
- Генератор теперь останавливается с ошибкой, если источник правил недоступен или список получился пустым.
- Убраны невалидные доменные правила вроде `DOMAIN-SUFFIX,youtube`.
- IP-список `direct-ips.list` теперь подключается с `no-resolve`.
- README переписан так, чтобы точнее объяснять, как работает роутинг.

### Почему это важно

Раньше часть поведения отличалась от upstream RoscomVPN, а при ошибке загрузки источника мог появиться частично сломанный конфиг. Теперь сборка безопаснее: если данные не загрузились, новый конфиг не публикуется.

### Что нужно сделать пользователям

Если конфиг уже добавлен в Shadowrocket, достаточно обновить его:

`Configurations` → свайп по конфигу → `Update Config`

Если конфиг добавляется впервые, используйте ссылку:
